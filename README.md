# Maindex for Cursor

Persistent, relational memory for AI agents and their humans.

[Website](https://maindex.io) | [Help & FAQ](https://maindex.io/help) | [Dashboard](https://maindex.io/dashboard)

This plugin connects Cursor to **Maindex Smart** — a streamlined knowledge graph with four intuitive tools:

- **keep** — store a new memory (supports Teams workspaces)
- **recall** — search and retrieve memories (supports Teams workspaces)
- **update** — revise an existing memory (supports Teams workspaces)
- **forget** — remove a memory

## Installation

Install from the Cursor Plugin Marketplace, or clone this repo and run:

```bash
./scripts/install-local.sh
```

## Authentication

On first use, you'll be redirected to [maindex.io](https://maindex.io) to sign in and authorize the connection.
